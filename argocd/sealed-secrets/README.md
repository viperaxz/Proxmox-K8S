# Sealed Secrets

This directory contains sealed secrets generated by `bootstrap.sh`.

## ⚠️ Important

The files in this directory are **encrypted** and safe to commit to Git.

- `cloudflare-credentials.yaml` - Cloudflare API credentials for DNS challenge
- `grafana-credentials.yaml` - Grafana admin credentials

## How Sealed Secrets Work

1. The Sealed Secrets controller is installed in the cluster
2. Secrets are encrypted using the controller's public key
3. Only the controller can decrypt them
4. Encrypted secrets are safe to store in Git

## Regenerating Secrets

If you need to regenerate secrets (e.g., new cluster, rotated credentials):

```bash
./argocd/bootstrap.sh secrets
```

## Manual Secret Creation

To create a new sealed secret manually:

```bash
# Create the secret (dry-run)
kubectl create secret generic my-secret \
    --namespace my-namespace \
    --from-literal=key=value \
    --dry-run=client -o yaml | \
    kubeseal --format yaml > sealed-secret.yaml

# Apply it
kubectl apply -f sealed-secret.yaml
```

## Backup

The Sealed Secrets controller's private key is critical. Back it up:

```bash
kubectl get secret -n sealed-secrets -l sealedsecrets.bitnami.com/sealed-secrets-key -o yaml > sealed-secrets-key-backup.yaml
```

Store this backup securely (NOT in Git).
